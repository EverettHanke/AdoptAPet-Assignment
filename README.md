# AdoptAPet-Assignment

This project was created as a basic setup for an introductory JavaScript class. It was developed as part of my role as a Supplemental Instruction leader to help students learn the fundamentals of JavaScript and HTML.

## Description

AdoptAPet-Assignment is a simple web application designed to teach students the basics of JavaScript and HTML. The project involves creating a pet adoption site where users can view and adopt pets. This assignment helps students understand how to manipulate the DOM, handle events, and work with basic HTML structures.

## Installation

No specific installation steps are required. Simply clone the repository and open the `index.html` file in your web browser to view the application.

```sh
git clone https://github.com/EverettHanke/AdoptAPet-Assignment.git
cd AdoptAPet-Assignment
